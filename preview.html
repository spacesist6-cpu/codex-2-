활동 01검토됨 ✓

파이썬을 활용한 CSV 데이터 처리 활동에서 결측값의 의미를 비교하고 조건에 맞는 처리 방법을 선택함. 코드의 실행 결과를 검증하며 정보 교과 개념을 실제 문제에 적용하는 태도를 보임.

활동 02검토됨 ✓

반복문과 리스트를 활용해 평균을 계산하는 과정에서 자료구조와 연산의 관계를 스스로 설명함. 오류 원인을 찾아 수정하고 결과를 기록하는 논리적 문제 해결 과정을 보여 줌.

활동 03검토됨 ✓

실행 오류를 원인별로 분류하고 수정 전후 결과를 비교함. 과정을 차분히 기록하며 오류를 개선의 기회로 활용하는 자기주도적 학습 태도가 돋보임.
